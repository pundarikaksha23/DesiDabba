# Desi Dabba

Premium React website for Desi Dabba, built with Vite, TypeScript, Tailwind CSS, Framer Motion, Vitest, and Playwright.

## Requirements

- Node.js
- npm

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
npm run test
npm run test:e2e
```

## Demo Notes

- The production build is generated in `dist/`.
- Fonts use universal browser-safe stacks, so no external font downloads or special installed fonts are required.
- Website imagery is bundled locally from `src/assets/images/`.
- Contact details and SEO domain values are centralized in `src/config/site.ts`.
- Routes and metadata are centralized in `src/config/routes.ts`.
